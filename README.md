# NaviVoge

Proyecto para conectar un smartphone con la pantalla original de una Voge DS900X
mediante Carbit/EasyConnect y realizar mirroring de aplicaciones.

## Objetivo

- Escanear el QR de la Voge.
- Obtener los parámetros de conexión Wi-Fi.
- Conectar el smartphone a la red de la moto.
- Establecer la comunicación Carbit/PXC.
- Implementar mirroring mediante MediaProjection.
- Mantener la proyección activa con la pantalla del smartphone bloqueada.
- Proyectar Google Maps, Waze, Wikiloc y otras aplicaciones.

## Desarrollo inicial

La interfaz se desarrolla inicialmente como una aplicación web mediante XAMPP.
La parte que requiera APIs Android se implementará posteriormente de forma nativa.
