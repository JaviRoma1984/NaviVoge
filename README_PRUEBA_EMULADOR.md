# NaviVoge — Modo de prueba QR para emulador

Esta versión añade un botón temporal **Probar con QR de ejemplo**.

Sirve para probar en el Pixel 7 virtual el flujo completo sin necesitar una cámara física:
1. Agregar escaneando QR.
2. Probar con QR de ejemplo.
3. NaviVoge recibe una cadena simulada.
4. La interpreta.
5. Se muestran los campos.
6. Se asigna un nombre.
7. Se guarda el vehículo.
8. El vehículo aparece en el desplegable.

Datos ficticios usados:
modelid=37501;ssid=VOGE-TEST;pwd=88888888;auth=WPA2;mac=E0:EE:00:00:00:01

El botón es temporal y lo eliminaremos cuando validemos el flujo con el QR real de la moto.
